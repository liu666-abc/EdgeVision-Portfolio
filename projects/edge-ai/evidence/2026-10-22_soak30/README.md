# 2026-10-22 30 分钟全链路稳定性测试

## 目的

验证 RDK X5 上的完整只读感知链路在持续负载下是否稳定：

- ROS2 视频源；
- YOLOv8n INT8 BPU 检测；
- Kalman + IoU/中心距离跟踪；
- MJPEG 上位机；
- 状态 API 和板端资源采样。

## 工况

- 输入：OpenCV 官方 `vtest.avi`。
- 原始视频约 10 FPS，本次强制按 25 FPS 回放作为压力工况。
- 分辨率：`768x576`。
- ROS domain：`59`。
- 相机和检测器目标：约 25 FPS。
- **散热条件：用户已安装并运行风扇；本测试是 fan-on 工况。**
- 本记录**不计入“无风扇 30 分钟”**。
- 不启动底盘、雷达、STM32。
- 采样间隔：5 秒。
- BPU 温度保护：`65 °C`。

## 判读

- 30 分钟内没有进程退出、接口中断、热保护停机或明显 FPS 退化。
- 内存首尾均为 `1099 MB`，没有泄漏趋势。
- 检测器 p95 `25.04 FPS`，基本追平 25 FPS 输入。
- 单帧总耗时 p95 `26.95 ms`，仍小于 25 FPS 的 `40 ms` 帧预算。
- BPU 和 DDR 全程保持最高频率，没有热降频。

## 边界

- 这是视频回放压力测试，不是覆盖全量 Astra RGB-D、Nav2、雷达和底盘的现场测试。
- BPU 占用率只有约 9%，说明当前瓶颈主要是 CPU 预处理和解码，不构成 BPU 饱和测试。
- 强制 25 FPS 会比原始视频播放更快，但不改变单帧计算量。
- 只记录板端状态 API 的采样值，不是逐帧硬件计数器。
- 30 分钟结果不能外推为 24 小时长期稳定性。
