Nav2 控制台怎么用

先看当前模式

页面顶部状态条会直接说明当前是否只是地图预览、雷达是否在线、Nav2 action 是否就绪。

ACTION SERVER READY：可以设置初始位姿和发送导航目标 WAITING：地图或雷达可看，但导航栈未就绪 ROS OFFLINE：检查 8091 服务、ROS_DOMAIN_ID 和 DDS

地图怎么操作

  1. 拖动地图：选择左侧手形工具后拖动，或直接拖动空白区域。
  2. 缩放：鼠标滚轮；适应全图：左侧四角图标。
  3. 选目标：点击地图图钉工具，再点击地图位置。
  4. 设初始位姿：点击十字准星工具，再点击机器人实际位置。

第一次导航的顺序

  1. 修好 `/dev/wheeltec_controller` 底盘别名。
  2. 点击右侧“启动导航”，等待 `ACTION SERVER READY`。
  3. 确认车在实际建图起点后，点击“A4 起点 0,0,0”。
  4. 点击“设为初始位姿”，等待 LOCALIZATION 变为 GOOD。
  5. 选择导航目标，勾选安全确认，再点“发送导航目标”。

现在为什么不能导航

如果页面显示 WAITING，并且 Robot Pose 是 `--`，通常是底盘没有启动、AMCL 没有运行，或者 `map -> base_footprint` TF 不存在。此时不要继续点目标按钮。
